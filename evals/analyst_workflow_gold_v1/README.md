## 数据来源与合理性

业务订单数据复用旧开发集`evals/gold_v1/fixtures.json`中的订单、明细、退款及目标。保留订单与明细粒度和一单多退款；本版明细去掉单位成本列，4月华东目标改为0，4月华北目标本来缺失。改动只发生于新集副本，旧数据和旧成绩不变。销售、退款、净利润及目标是否可计算由真实提供的字段决定。

新增两套原创合成数据：

- `dirty/orders.csv`：7笔新增订单，含1条状态空格、1个不可解析日期、1个未知金额、1笔取消单、1笔次月订单和1笔显式零金额。用于一次真实的新增数据准备与清洗授权任务，不将这些问题堆进其他题。
- `presentation/daily_sales.csv`：两地区、两互斥渠道的4个有记录日；指定五天窗口中2月3日没有记录，另有两个已记录的未知金额单元和一个显式零。长地区名称保留原文，用于不完整日报交付。

首版是小数据、同业务域的工作流回归集。复用数据已经被开发过程使用，新增数据也不是第三方隐藏数据；不宣称跨行业、大表、并发或外部盲测。A02两月订单数相等，能确定量的效应为0；本版不以此证明复杂结构效应识别能力。

题面从分析师的成果需求出发，不要求默认SQL、指定内部字段、固定路由或非必要图型。自动准备、事实核验和产物整理由Agent承担；业务决定由分析师按脚本作出。没有必要时不要求澄清，也不要求清洗。

## 标准答案如何核对

`evals/analyst_workflow_dataset.py`从原始记录用Decimal、Counter和明确的日期/分组规则独立计算；单独编写参考SQL在DuckDB执行并对比全部21组结果，不导入生产Agent的指标、准备或清洗计算逻辑。

几个可手算的锚点：

- 2月商品销售额590元、4笔已完成订单、客单价147.5元。
- 1月715元，2月比1月少125元；渠道差额之和应为-125元。
- 2月已结退款50元，退款后金额540元；pending的25元不扣。
- 状态去空格前：可识别2月且精确匹配状态的3笔订单，已知金额100元、未知金额1笔；去空格后为4笔、已知150元、未知仍1笔。不可解析日期的200元不能擅自归入2月。
- 一季度7位购买客户；首轮按订单渠道独立计数合计8人，改成首购渠道归属后合计7人。两种定义有不同分母，不能混用。
- 线上日报2月3日无记录，2月4日为明确的0元；二者不能同样填0。

6项自检覆盖数据/脚本对应、21组SQL交叉核对与手算锚点、错误退款与未知补零被判不一致、问题不泄露后续答复/答案、故意破坏教师会使交叉核对失败，以及冻结文件和实际CSV一致性。上述检查是教师与材料核验，不是Agent的运行成绩。

## 执行协议

1. 每任务新建隔离会话，导入该profile目录下全部CSV；不导入`answers.json`、参考SQL、案例ID、后续答复和评分要求。commerce只需4张表，其他profile各1张。
2. 首次只发送该任务的`public_input`与T1消息；后续只发送当前轮消息。`public_input()`使用字段白名单；不能把整份题册作为模型上下文。
3. 有决策环节时，先保存Agent实际提出的建议、理由和待定项，再按该轮固定分析师答复继续。A01若未确认就正式计算，记录失败，不能用之后补确认覆盖过去的违规。无决策缺口时，不额外强迫Agent提问。
4. A06只允许预览授权的规则；应用必须绑定刚才实际产生的方案并走产品确认入口，不能测试员直接改文件。撤销也走产品入口。发现不支持的对照如实记录，不能由评分者代算后贴回Agent回答。
5. 保存每轮提问、实际回复、工具结果、准备/确认记录、数据版本、图表和下载产物。表格按语义建立映射，映射理由单独保留；数值、未知、分母和时间范围必须正确。
6. 图表布局需要查看实际渲染；CSV需要实际下载并逐行与对应标准核对。仅`chart_spec`或链接存在不能证明可读性、下载与完整交付通过。
7. 如果环境中断，记环境故障及尚未完成范围；保留原始记录。首轮结果不被重试覆盖，修复后的新运行另建记录。不允许只挑最好的一次成绩。
8. 按审阅模板逐项保存证据。关键错误单列失败，不用平均分抵消。只有所有适用项完成且无关键错误，业务任务才通过。

旧`run_gold_eval.py`只认识原来的三个局部回归集，**不能把本集改名塞进去**。首轮新增`scripts/run_analyst_workflow_eval.py`，通过实际上传与`/ask`接口顺序执行20条消息，保留历史、工具结果、下载及图表配置。它不自动替分析师评分，也不认证浏览器展示；首轮按固定分析师文本作确认/追问，没有注入参考计划或黄金答案。

## 复现黄金集自检

在项目根目录，用PowerShell7和现有虚拟环境：

```powershell
$env:PYTHONUTF8='1'
./.venv/Scripts/python.exe scripts/build_analyst_workflow_gold.py --check
./.venv/Scripts/python.exe -m pytest backend/tests/test_analyst_workflow_gold.py -q
```

`--check`不覆盖标准、不调用模型。无参数构建只用于首次生成，存在manifest后拒绝覆盖。新版数据、题目或标准若要修订，应建立明确的新版本并保留旧版依据。

题库构建阶段的模型费用为0；冻结的`reference-check.json`记录的是该阶段自检，不是实时Agent成绩。后续首轮真实模型测试完成65次请求，应用估算约1.8414元，实际费用以服务商账单为准；已有实际CSV下载证据，但尚无浏览器目视验收。题库构建完成与Agent验收通过是两件事。
