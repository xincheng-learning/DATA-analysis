# DataPilot 黄金集 v1 题册

当前为未运行真实模型的黄金标准，不是项目成绩单。

72个案例，78次提问；其中6个两轮案例必须从新会话开始顺序执行。36开发、18验证、18最终测试。

每个案例使用指定profile，只有commerce的6张表同时加载；quality、stats与各调查profile分别独立加载。不要把不同sales夹具混进同一会话。

被测模型只能得到问题、该profile业务口径、真实schema和实际历史／工具结果。不能传expected答案、reference SQL、case ID、family、fixture目录名或评分量表。

## 基础汇总

### G001　order_grain

集合：development；数据：commerce；模式：quick。

业务口径：合成数据，金额单位人民币元。orders一行一单，items一行一条商品明细；销售、客单价、利润和履约默认只含status=completed。销售额=sum(quantity*unit_price)，不含运费；毛利=sum(quantity*(unit_price-unit_cost))；净销售额=销售额减status=settled的退款，不减运费。订单计数按order_id，退款事件可能一单多条，联表前保持粒度。targets按month+region唯一，目标缺失不当作0；目标为0时达成率为NULL。最近月份相对数据最大订单日期2026-04-30，不相对系统今天；月按自然月，日期边界按题目。customers含没有已完成订单的客户。只有明确要求的订单、明细、客户粒度才计算相应分母。quality/stats是独立数据配置，不混入主商业表；quality有刻意设置的缺失、重复与非法值。

要检验的错误：把items行数当订单数。

**第1轮问题**：全部数据中，已完成订单总数是多少？按订单去重，不计取消单。

允许路线：sql。

参考结果（可用等价SQL／代码，列别名需显式对应）：

```json
[
  {
    "order_count": 15
  }
]
```
