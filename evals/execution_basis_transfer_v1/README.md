# 固定计算依据：非电商迁移检查

这不是盲测：题目在实现后编写，用于检查同一工作流能否迁移到能耗与仪表场景，不代表真实业务总体通过率。

导入 `data/energy/runs.csv` 后询问总能耗并修改车间筛选；导入 `data/observations/` 下两张表后询问登记仪表总用量，再由分析师明确修改无记录处理规则。

`cases.json` 仅包含公开数据说明与当前轮问题；`answers.json` 存储独立手算结果，不发送给 Agent。`manifest.json` 固定原始数据、题目和答案。

独立预期：总能耗 30 kWh，A 车间 22 kWh。仪表 A 无记录，B 全未知，C 部分未知，D 真实零，E 为 2+3=5；确认来源完整且无记录为零之后，仅 A 从未知改成0，不能把 B/C 补零。

首次 4 轮数值及实际 CSV 核对 3 轮通过，X02 规则变更失败；补编译守卫后的定向复测阻止了错误执行，但一次计划修正后仍有分组错误，任务未完成。失败记录保留，详见 `docs/固定计算依据与泛化实测-2026-11-16.md`。
